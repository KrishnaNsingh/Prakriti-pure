# Prakriti Pure – E-commerce Platform

[![Deployment Status](https://img.shields.io/badge/Deployment-Live-success)](https://your-deployment-link.com)
[![Tech Stack](https://img.shields.io/badge/Stack-MERN-blue)](#tech-stack)

Prakriti Pure is a full-stack e-commerce application designed to provide users with seamless access to natural and organic products. The platform focuses on a minimalist, nature-inspired user experience combined with a robust backend for secure transactions and inventory management.

---

## 🚀 Key Features

* **User Authentication:** Secure JWT-based login and registration with protected user profiles.
* **Product Management:** Dynamic product catalog with filtering, detailed descriptions, and high-quality imagery.
* **Shopping Cart:** Persistent cart functionality using Redux Toolkit/Context API.
* **Responsive UI:** Fully optimized for mobile, tablet, and desktop views.
* **Admin Dashboard:** Secure routes for managing products, categories, and viewing orders.
* **Secure Payments:** Integration-ready for payment gateways (e.g., Razorpay/Stripe).

---

## 🛠 Tech Stack

**Frontend:**
* React.js (Functional Components & Hooks)
* Tailwind CSS (Styling)
* Redux Toolkit (State Management)
* Axios (API Requests)

**Backend:**
* Node.js & Express.js
* MongoDB & Mongoose (Database & Modeling)
* JSON Web Tokens (Authentication)
* Cloudinary (Image Hosting)
